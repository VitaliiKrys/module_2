# Document Classifier

## Опис
Electron застосунок для автоматичної класифікації документів.

## Функціонал
- Навчання моделі на текстових файлах
- Автоматична класифікація документів
- Логування критичних дій у зовнішній файл (`app.log`)
- Використання зовнішнього конфігураційного файлу (`config.json`)
- Вибір файлів через системний діалог

## Покращення (fix)
- Додано перевірку порожніх файлів
- Обробка помилок читання файлів
- Винесення шляхів у `config.json`
- Логування помилок у файл

## Запуск проєкту
```bash
npm install
npm start
```
